# ASSB Lab

**Open Research Tools for All-Solid-State Batteries & Materials Science**

We develop research software and computational tools to accelerate the understanding and development of all-solid-state batteries and functional materials.

全固体電池や機能性材料の研究を支援する、解析・計算・可視化ツールを開発・公開しています。

**[Official Website](http://www.assb.iir.isct.ac.jp/)**

## Research Areas

- **All-Solid-State Batteries** — Solid electrolytes, lithium alloy anodes, and electrode–electrolyte interfaces.
- **Crystal Chemistry** — Crystal structures, coordination environments, ionic transport pathways, and structure–property relationships.
- **Electronic Structure & Interfaces** — Energy-level alignment, photoelectron spectroscopy, and interfacial stability.
- **Computational Materials Science** — Thermodynamic modeling, numerical simulation, data analysis, and scientific visualization.

## Featured Projects

| Project | Description |

| [Crystal Site Matcher](https://github.com/assb-lab/crystal-site-matcher) | Crystal-site analysis, ionic substitution, and ion-transport descriptors. |

| [Li-Mg Diffusion Simulator](https://github.com/assb-lab/li-mg-diffusion-simulator) | Numerical simulation of lithium diffusion in Li-Mg alloy anodes. |

| [Band Alignment Simulator](https://github.com/assb-lab/band-alignment-sim) | Electrostatic modeling and band alignment in multilayer systems. |

## Open Science & Development

We build tools that connect experimental observations with physical models and computational analysis.

Our repositories include interactive web applications, scientific simulators, analysis utilities, and experimental research software. Some projects are under active development.

See individual repositories for documentation, source code, and license information.
